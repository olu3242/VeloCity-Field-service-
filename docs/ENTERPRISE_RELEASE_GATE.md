## Deployment Instructions

1. Confirm branch `claude/build-velocity-field-service-JVoOY` is green on CI
2. Request PR review from a second engineer
3. Merge via squash or merge commit (not rebase, to preserve commit trailers)
4. Verify `/admin/runtime/workstreams` renders correctly post-deploy
5. Verify `GET /api/admin/runtime/workstreams` returns 200 with valid payload
6. Monitor worker health dashboard for 10 minutes post-deploy
7. Confirm no new error spikes in the automation_runs table

## Rollback Plan

If the release gate fails post-deploy:
1. Revert the merge commit: `git revert -m 1 <merge-commit-sha>`
2. Deploy the revert commit
3. The WRF is additive — reverting removes the new library and dashboard, but leaves existing functionality intact
4. No database rollback is required (no migrations were applied)
