## Health States

| State | Meaning |
|-------|---------|
| `healthy` | All dependencies reachable; within SLA |
| `degraded` | One or more non-critical dependencies unavailable; serving with reduced capability |
| `offline` | Critical dependency unavailable; not serving requests |

## SLA Enforcement

SLAs are enforced at the executor layer (`src/lib/workstream/executor.ts`). Any workstream exceeding its declared `slaMs` emits a warning in the runtime state (`warnings[]`) and increments the latency violation counter.

## Recovery Ladder

All workstreams follow the same recovery order:

1. **Retry** — exponential backoff with jitter (max 3 attempts by default)
2. **Fallback** — secondary implementation (cached data, reduced feature set)
3. **Degraded mode** — serve with degraded flag set; user is notified
4. **Manual** — circuit open; operator intervention required

## Live Dashboard
