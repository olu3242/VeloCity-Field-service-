# VeloCity Execution Resource Management

## Overview

The resource manager (`src/lib/economy/resource-manager.ts`) tracks AI execution costs, manages per-tenant token budgets, and provides real-time cost visibility across the platform.

---

## Cost Tracking

Every AI agent execution is recorded:

```typescript
recordExecution("IVY", tenantId, 1842, 2140);
// tokensUsed: 1842
// latencyMs: 2140
// estimatedCostUsd: 1842 × $0.000009 = $0.0166
```

Cost model: **$0.000009 per token** (blended Claude Sonnet input/output average).

Actual pricing: $3/1M input tokens + $15/1M output tokens → blended ≈ $9/1M tokens for typical AI workloads.

---

## Per-Tenant Budgets

```typescript
const budget = getOrCreateBudget(tenantId);
// {
//   tenantId: "tenant-abc",
//   dailyTokenBudget: 1_000_000,
//   dailyTokenUsed: 284_500,
//   hourlyCallLimit: 200,
//   hourlyCallCount: 47,
//   lastResetAt: "2025-05-26T00:00:00Z"
// }
```

Budget resets every 24 hours (`lastResetAt` tracks the window).

### Budget Enforcement

```typescript
const check = checkBudget(tenantId, 2000);
// { allowed: true } — or
// { allowed: false, reason: "Daily token budget exceeded" }
```

Budget checks should be called before `dispatchAgent()` for budget-sensitive tenants. Enforcement is advisory in the current implementation — the orchestration layer reads this signal and can throttle.

## Cost Reports

```typescript
getCostReport(tenantId);
// {
//   totalCostUsd: 12.47,
//   totalTokens: 1_385_000,
//   totalCalls: 847,
//   avgCostPerCall: 0.0147,
//   byAgent: {
//     "IVY": 4.23,
//     "FINN": 2.18,
//     "MAX": 1.95,
//     ...
//   }
// }
```

`getCostReport()` (no tenantId) returns platform-wide totals — admin visibility into total AI infrastructure cost.

## Tier Budget Defaults

| Tier | Daily Token Budget | Hourly Call Limit |
|---|---|---|
| Standard | 1,000,000 | 200 |
| Premium | 5,000,000 | 1,000 |
| Enterprise | 50,000,000 | 10,000 |

Budget limits are advisory — hard enforcement (blocking calls) requires integration with `dispatchAgent()` and governance policy `ai-execution-rate-limit`.

---

## Cost Optimization Recommendations

Generated by `getBusinessIntelligence()`:

- If IVY cost > 40% of total: "Increase auto-resolution threshold to reduce IVY invocations"
- If avg tokens per call > 3000: "Review agent prompts for verbosity — reduce max_tokens limits"
- If fallback rate > 20%: "Consider cost is near zero — AI unavailable most of the time"
